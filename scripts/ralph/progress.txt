## Codebase Patterns
- Database path: Use `DATA_DIR` env var in Docker, calculate from file path for local dev
- Dictionary keys: Use SLP1 encoding internally for standardized Sanskrit lookup
- API response format: Always return `{"success": true/false, "data": ...}`
- Flask URL special chars: Use `<path:param>` converter for Sanskrit words
- Script detection: Devanagari = `[\u0900-\u097F]`, IAST = diacritics, SLP1 = ASCII
- Frontend context pattern: types in .ts file, provider in .tsx, hook in hooks/
- Dharmamitra: Use `dharmamitra-sanskrit-grammar` package, lazy init to avoid startup delay
- Dhatu identification: lemma = dhatu for verbs, gana from DHATU_GANA_MAP lookup
