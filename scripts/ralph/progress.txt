## Codebase Patterns
- Database path: Use `PROJECT_ROOT = os.path.dirname(os.path.dirname(os.path.dirname(__file__)))` from `backend/app/__init__.py` to get project root
- Data directory: All data files (db, dictionaries, vidyut-data) should go in `data/` at project root
- Model helpers: Use `pk()` and `foreign_key()` from `app.models.base` for consistent column definitions
- Dictionary keys: Use SLP1 encoding internally for standardized Sanskrit lookup
- Text hierarchy: Text → TextSection → TextBlock (generic structure supports any Sanskrit text)
- Script imports: Use `sys.path.insert(0, BACKEND_DIR)` to import from `app` module in scripts
- Querying models: Use `db.session.query(Model).filter_by()` not `Model.query.filter_by()` (Flask-SQLAlchemy v3 style)
- Sanskrit transliteration: Use `indic-transliteration` library for ITRANS↔IAST↔Devanagari conversion
- Idempotent scripts: Clear existing data before re-inserting to allow safe re-runs
- Backend port: Default is 5001 (port 5000 blocked by macOS AirPlay), configurable via PORT env var
- API response format: Always return `{"success": true/false, "data": ...}` or `{"success": false, "error": "..."}`
- Flask URL special chars: Use `<path:param>` converter when route params may contain special characters (e.g., Sanskrit words)
- Script detection: Devanagari = `[\u0900-\u097F]` Unicode range, IAST = diacritics (āīūṛṃḥ etc.), SLP1 = ASCII fallback
- Vidyut usage: Import as `from vidyut.vidyut import cheda`, init as `cheda.Chedaka(data_path)` where data_path is parent vidyut-data directory
- Vidyut input: Chedaka.run() accepts SLP1 only - convert other scripts first
- Frontend API config: Use `import.meta.env.VITE_API_URL || 'http://localhost:5001/api'` for backend URL
- Tailwind v4: Use `@import "tailwindcss"` instead of `@tailwind` directives, and `@tailwindcss/postcss` plugin
- React Query: Initialize QueryClient in main.tsx, use custom hooks in `src/hooks/` for data fetching
- Route structure: `/pada/:padaSlug` for section view, `/pada/:padaSlug/sutra/:sutraNumber` for block view
- Sanskrit fonts: Import Noto Sans/Serif Devanagari from Google Fonts, apply via `.font-serif` class
